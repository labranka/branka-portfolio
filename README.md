# branka-portfolio

Personal portfolio of Branka Lakićević. Next.js 16 (App Router), Tailwind CSS 4, Framer Motion.

- `npm run dev` then open http://localhost:3000
- Content: `src/content/projects.ts` (projects, order, `hidden: true` to hide), `src/components/HowIWork.tsx`, `src/components/About.tsx`
- Images: `public/work/<slug>.png` (1600x1000, 16:10); portrait in `public/portrait.jpg`; CV in `public/Branka-Lakicevic-CV.pdf`
- Deploy: push to GitHub and import in Vercel (zero config)
